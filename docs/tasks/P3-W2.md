## Hard rules for detectors
- **Read-only.** Use scan data, file reads and `env.Runner` for listing commands. forbidcheck applies.
- **Never run `pnpm`, `yarn` or `npm` to discover paths.** On this Mac they're Corepack shims, and querying them **downloaded binaries**. Use the known default locations:
  - npm: `~/.npm/_cacache`
  - pnpm: `~/Library/pnpm/store`
  - Yarn classic: `~/Library/Caches/Yarn`

  Running those tools as the *native cleanup command* at apply time (Phase 6) is fine. Say so in `explain` ("may download the package manager first").
- `brew cleanup -n` and `brew autoremove -n` are the tool's own dry-runs and are fine to run through `env.Runner`. Use a timeout of 60 s; `platform.Command` has a `Timeout` field.
- If the Docker daemon isn't reachable (real fixture `docker_not_running.txt`), or a tool isn't installed, return `nil, nil`.
- `NativeArg` comes verbatim from the tool's listing (`ollama list` names). Reject whitespace, `/` (except inside a valid ollama `name:tag`, which has no `/` for library models; if `/` appears, skip that model), and shell characters.
- Quarantine targets must be under home and match the recipe's `allow`. The classifier (P3-W3) checks each one with `safety.CheckTarget`.
- Sizes come from the scan (`SourceMeasured`) or the tool (`SourceTool`, e.g. brew's "would free approximately 377MB"). Otherwise use `SourceUnknown` with a reason. Never use 0 to mean unknown.

**Docker** (`docker.yaml`). Detector `docker_df` parses `docker system df --format '{{json .}}'` (one JSON object per line: `Type`, `TotalCount`, `Active`, `Size`, `Reclaimable`; sizes are human strings like `"2.3GB"` and `"1.1GB (45%)"`). It emits per recipe via a `params.type`:
- `docker.build_cache`: Type `Build Cache`. Native `docker builder prune -f`, SAFE.
- `docker.dangling_images`: use `docker images -f dangling=true --format '{{json .}}'` in its own detector `docker_dangling`. Native `docker image prune -f`, SAFE.
- `docker.unused_images`: Type `Images`, reclaimable. Native `docker image prune -a -f`, CAUTION.
- `docker.stopped_containers`: Type `Containers`, reclaimable. Native `docker container prune -f`, CAUTION.
- `docker.volumes`: Type `Local Volumes`. Advise, ADVISE. **Irreplaceable data:** list sizes and say how to inspect them (`docker volume ls`, `docker system df -v`).
- `docker.raw_disk`: detector `path`, `~/Library/Containers/com.docker.docker/Data/vms/0/data/Docker.raw` (sized by the scan; allocated, not logical). Advise. Explain the Docker Desktop disk limit and that pruning frees space inside the image.
