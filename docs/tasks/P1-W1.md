## Semantics
- **Bytes:**
  - vm_stat values are page counts with a trailing `.`. Bytes = pages × page size from the header line `(page size of N bytes)`.
  - Swap units in `vm.swapusage` are `K`/`M`/`G` with binary multipliers (e.g. `5120.00M` = 5120 × 1024²).
- **Memory fields:**
  - `FreeBytes` = "Pages free"
  - `ActiveBytes` = "Pages active"
  - `InactiveBytes` = "Pages inactive"
  - `WiredBytes` = "Pages wired down"
  - `CompressedBytes` = "Pages occupied by compressor"
- **CollectMemory:** gets `TotalBytes` from `sysctl -n hw.memsize`, `FreePercent` from `memory_pressure -Q` (-1 on failure), and `Pressure` from `sysctl -n kern.memorystatus_vm_pressure_level`. It returns an error only if vm_stat itself fails, and fills the rest best-effort.
- **ParsePS grouping:**
  - Use the basename of `comm`.
  - Map helper processes to their app: strip suffixes like ` Helper`, ` Helper (Renderer)`, ` Helper (GPU)`, ` Helper (Plugin)` and ` Web Content`. Also use the `.app` bundle name when the path contains `/<Name>.app/` (e.g. `/Applications/Google Chrome.app/.../Google Chrome Helper` → `Google Chrome`).
  - Group **known dev-heavy processes** under friendly names:
    - `com.docker.*`, `Docker Desktop`, `vpnkit`, `qemu-system-*` (when the path is under Docker) → **"Docker"**
    - `qemu-system-*`, `emulator*` (Android) → **"Android Emulator"**
    - `node` → **"Node.js"**
    - `ollama`, `ollama_llama_server` → **"Ollama"**
    - `Xcode`, `SourceKitService`, `XCBBuildService` → **"Xcode"**
    - `java` / `studio` under `Android Studio.app` → **"Android Studio"**
    - `Simulator`, `launchd_sim` → **"iOS Simulator"**
  - Sort by RSS descending. Ties break by name. Return the top `n`, where `n <= 0` means all.
  - `rss` is in KB.
- **Commands:** use fixed argv only, via `platform.Command`, with no shell. Use the default timeout unless noted.
  - `sysctl hw.model hw.memsize hw.ncpu machdep.cpu.brand_string`
  - `sw_vers`
  - `vm_stat`
  - `sysctl -n hw.memsize`
  - `memory_pressure -Q`
  - `sysctl -n kern.memorystatus_vm_pressure_level`
  - `sysctl -n vm.swapusage`
  - `ps -axo rss=,comm=`
- **Errors:** wrap with context (`probe: vm_stat: …`). A non-zero exit code from a command is an error that includes trimmed stderr.
