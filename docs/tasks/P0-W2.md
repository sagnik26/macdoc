## 1. `internal/sandbox` (implement the contract; don't change exported API)
- `Root()`:
  - If the env var is unset or empty, return `"", false, nil`.
  - If it's set, the value must be absolute and exist as a directory. Canonicalize it with `safety.Canonicalize`.
  - **Reject** `/`, the user's home (`os.UserHomeDir`, canonicalized), and any ancestor of home. Return an error explaining why.
- `Check(path)`:
  - If inactive, return nil.
  - If active, return nil only if `path` is strictly **inside** the root (not equal to it), using `safety.Within`.
  - If the env var is set but invalid, `Check` **fails closed** and returns an error for every path.
- Tests use `t.Setenv` and cover each rejection, the inside/outside/equal cases, a symlink pointing out of the sandbox (caller passes a canonical path, so test it with the canonicalized form), and fail-closed behavior.

## 2. `internal/testutil/fstree`: fake filesystem builder
```go
type Entry struct { /* Path (relative to root), Kind, Size, Sparse, Target, Mode, ModTime */ }
func Build(t testing.TB, root string, entries ...Entry)
// Constructors:
func Dir(p string) Entry
func File(p string, size int64) Entry           // real allocated bytes
func Sparse(p string, logicalSize int64) Entry  // truncate-only, ~0 allocated
func Symlink(p, target string) Entry
func Hardlink(p, existing string) Entry
func (e Entry) WithMode(m os.FileMode) Entry     // e.g. 0o000 for EACCES dirs
func (e Entry) WithModTime(t time.Time) Entry
func DevHome(t testing.TB) string                // returns a temp home with a representative dev layout
```
- `Build` creates parent directories automatically and fails the test on any error.
- Directories with restrictive modes must be restored in `t.Cleanup` so `t.TempDir` cleanup works.
- `DevHome` creates (small sizes, fine for tests):
  - `Library/Developer/Xcode/DerivedData/{AppA-x,AppB-y}`
  - `Library/Developer/Xcode/Archives/2025-01-01/App.xcarchive`
  - `Library/Caches/{com.example.app,CocoaPods}`
  - `.gradle/caches`
  - `.android/avd/Pixel.avd`
  - `.npm/_cacache`
  - `code/web/{package.json,node_modules/x/index.js,.git/HEAD}`
  - `Documents/notes.txt`
  - `.ssh/id_ed25519`
  - `Library/Mobile Documents/x`
- Write tests for the builder itself (sizes, sparse vs allocated via `Stat_t.Blocks`, symlink not followed, hardlink nlink=2, mode cleanup).

## 4. `tools/forbidcheck` + `scripts/forbidcheck.sh`
A small Go program using `go/parser` + `go/ast` (not grep) so aliased imports are caught. `scripts/forbidcheck.sh` runs `go run ./tools/forbidcheck ./...`.
- **Scope:** all non-`_test.go` files in the module **outside** `internal/executor`.
- **Forbidden:**
  - calls to `os.Remove`, `os.RemoveAll`, `os.Rename`, `os.Truncate`
  - `syscall.Unlink`/`Rmdir`/`Rename`, `unix.Unlink*`/`Rmdir`/`Rename*`
  - `exec.Command` / `exec.CommandContext`
  - any string literal equal to `"sh"`, `"bash"`, `"zsh"` or `"sudo"` used as the first argument to an exec call
- **Allowlist** via `tools/forbidcheck/allow.txt`, lines of `path:Func`. It starts with exactly:
  - `internal/platform/runner.go:exec.CommandContext` (the read-only runner)
  - anything `internal/testutil` legitimately needs (document why)
- Output is `file:line: forbidden call os.RemoveAll (only internal/executor may delete)`, with a non-zero exit.
- Write unit tests with in-memory source snippets: direct call, aliased import (`import x "os"; x.Remove(...)`), dot-import, allowlisted file, test file ignored.
