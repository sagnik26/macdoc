## Specification details (in addition to the doc comments)

### Canonicalize
- Reject: empty input, input containing `\x00`, and relative paths (`*Violation` with `RuleNotAbsolute` / `RuleInvalid`).
- `filepath.Clean` first, then resolve symlinks in the **parent** chain. Find the deepest existing ancestor, `filepath.EvalSymlinks` it, then append the remaining (non-existing) components. The **final component is never followed** even if it's a symlink.
- macOS has `/var`, `/tmp` and `/etc` as symlinks into `/private`, and EvalSymlinks handles these. Make sure `/var/folders/...` canonicalizes to `/private/var/folders/...`.
- NFC-normalize the result (`golang.org/x/text/unicode/norm`). Preserve case.
- It must be idempotent: `Canonicalize(Canonicalize(x)) == Canonicalize(x)`.

### Built-in protected paths
Use **system roots**: `/System`, `/usr`, `/bin`, `/sbin`, `/Library`, `/private`, `/cores`, `/Applications`, `/Volumes`, `/dev`, `/opt` (Homebrew is acted on only via `brew`, never by path), and `/` itself.

Use **home-relative paths** (under the policy's home):
- `Documents`, `Desktop`, `Pictures`, `Movies`, `Music`, `Public`
- `Library/Mobile Documents`, `Library/CloudStorage`, `Library/Mail`, `Library/Messages`, `Library/Photos`, `Library/Keychains`
- `Library/Application Support/MobileSync/Backup`, `Library/Application Support/macdoc`
- `.ssh`, `.gnupg`, `.aws`, `.config`, `.kube`, `.docker/config.json`, `.netrc`, `.npmrc`, `.pypirc`

Use **pattern rules**:
- any path whose components include `.git` is protected
- `Library/Containers/com.apple.*` (any container whose name starts with `com.apple.`) is protected
- if the **final** component matches `.env` or `.env.*`, or ends in `.sqlite`, `.sqlite3` or `.db`, it's protected

Also include the policy's `extraProtected` entries.

"Within a protected path" means equal to it or below it (component-wise, case-insensitive, NFC).

### Home containment exception (needed for tests)
If a **system root** is an ancestor of (or equal to) the policy's home, that system root does **not** protect paths *inside home*. It still protects everything outside home. Example: when home is `/private/var/folders/xx/T/test123/home` (a `t.TempDir()`), `/private` doesn't block `…/home/.gradle/caches`, but home-relative and pattern rules still apply. On a real Mac (`/Users/<name>`) this never triggers.

`NewPolicy` must reject a home that is relative, is `/`, or has fewer than 2 components (e.g. `/Users`).

### Depth rule
Under home, a target must be at least **2 components** below home. `~/.gradle` is rejected and `~/.gradle/caches` is allowed (if allowed by pattern). Home itself is rejected. Use `RuleTooShallow`.

### Allow patterns
- An absolute or `~`-prefixed pattern (`~` expands to the policy's home). Any other form is a non-match.
- `*` matches exactly one component (any characters except `/`, including an empty string within a component, like `filepath.Match`). `**` matches zero or more whole components. Other glob syntax (`?`, `[...]`) may be supported via `path.Match` per component.
- Matching is case-insensitive and NFC-normalized.
- Examples:
  - `~/Library/Developer/Xcode/DerivedData/*` matches `~/Library/Developer/Xcode/DerivedData/MyApp-abc` but **not** `…/DerivedData` itself, nor `…/DerivedData/MyApp-abc/Build`
  - `~/**/node_modules` matches `~/code/app/node_modules`

### CheckTarget order
Canonicalize, then protected checks, then depth rule, then allow-pattern match. Return the **first** violation as `*Violation`.

## Required tests
- Table-driven tests for every protected root and rule, including look-alikes that must **pass** the protected check: `~/DocumentsOld/x/y`, `/Systemx`, `~/Library/Containers/org.example.app/x`.
- Case and Unicode: `~/documents/x` is protected, and an NFD-encoded `é` path matches its NFC protected form.
- Symlinks built with `t.TempDir()`:
  - a symlinked parent pointing into a protected area is rejected
  - a final-component symlink is not followed
  - a symlink loop returns an error, not a hang
- `..` traversal: `~/Library/Caches/../../Documents/x` is rejected.
- Allow-pattern matching table, including the examples above.
- Home exception tests (temp home works) and `NewPolicy` rejections.
- **Fuzz tests** named exactly `FuzzCanonicalize` and `FuzzCheckTarget` (the Makefile runs these):
  - `FuzzCanonicalize`: never panics, and is idempotent when there's no error.
  - `FuzzCheckTarget`: never panics. If it returns nil, then `IsProtected` is false for the canonical path and the depth rule holds.
- Aim for **≥ 95% statement coverage** (`go test -cover ./internal/safety`).
