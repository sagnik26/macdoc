## Decisions

**D1 (R1-01, R1-02, R1-05): exact native argv allow-list.** In `load.go`, replace the deny-list logic in `lintArgv` with an **exact allow-list** of full argv sequences, where `{id}` is literal:

```
brew cleanup --prune=all
brew autoremove
docker builder prune -f
docker image prune -f
docker image prune -a -f
docker container prune -f
xcrun simctl delete unavailable
xcrun simctl delete {id}
xcrun simctl runtime delete {id}
npm cache clean --force
pnpm store prune
yarn cache clean
pip3 cache purge
uv cache prune
conda clean --all -y
ollama rm {id}
pod cache clean --all
avdmanager delete avd -n {id}
```

Any other argv fails `Validate` with `native argv not in the allow-list`. Keep `NativeTools` consistent with the list. Remove `allowedSubcommands` and `forbiddenArgs` if they're now redundant, but keep the shell-character check as defense in depth. Every recipe in the catalog must still load.

**D2 (R1-03): exact dry-run allow-list.** `dry_run_argv` must be empty or exactly one of:
```
brew cleanup -n --prune=all
brew autoremove -n
conda clean --all --dry-run
```
It must never contain `{id}`. Also make `runDryRun` (in `detect_system.go`) refuse any argv not in this set (a defensive check at the call site).

**D3 (R1-04): pattern lint knows the protected paths.** `lintPattern` rejects a pattern if any of the following is true:
- (a) Its leading components could match any home-relative protected root, or a descendant or ancestor of one. Compare component by component, case-insensitively, using `path.Match`. Treat a `**` occurring before the end of the root's components as "could match".
- (b) Its first two components below `~` are both wildcards.
- (c) Its final component could match `.git`, `.env`, `.env.local`, `x.sqlite`, `x.sqlite3`, `x.db` or `x.db-wal`.
- (d) It could match `~/Library/Containers/com.apple.<anything>`.

Use `safety.HomeProtected()`, which you add. All existing catalog patterns must still pass. If one doesn't, report it rather than weakening the lint.

**D4 (R1-13): precondition argument charset.** Arguments must match `^[A-Za-z0-9][A-Za-z0-9 ._-]*$`.

**D5 (R1-06): AVD paths.** `android_avds` and `android_avd_snapshots` only use an AVD directory that meets all of these:
- it canonicalizes strictly inside the AVD home
- its name ends in `.avd`
- it contains a regular `config.ini`
- `safety.Policy.IsProtected` is false for it, using a policy built from `env.Home`

Otherwise skip it. No finding is emitted.

**D6 (R1-07): safe file reads.** Add one helper, `readSmallFile(path string, max int64) ([]byte, error)`. It does `os.Lstat` and requires a regular file. It opens with `O_RDONLY|O_NONBLOCK|O_NOFOLLOW`, re-checks `f.Stat()` is a regular file, and reads through `io.LimitReader(max+1)`, returning an error if the file exceeds `max`. Default `max` is 64 KiB. Use it for **every** detector file read: AVD `.ini` and `config.ini`, nvm aliases, and anything else.

**D7 (R1-08): sizes.** `parseSize` rejects non-finite values, values ≥ 2^63 and values > 1 PB. Every per-row sum uses a checked add. On overflow or an absurd value the result is `SourceUnknown` with a reason, never a saturated or negative number.

**D8 (R1-09): UDID validation.** `detectSimctlUnavailable` sizes a device only if `validNativeArg(udid)` is true. Otherwise the device counts as missing.

**D9 (reserved NativeArgs, ambiguity 5).** `validNativeArg` also rejects reserved tool keywords, case-insensitively: `all`, `unavailable`, `booted`, `help`, `version`.

**D10 (R1-10): overlaps.**
- Add generic support to the `children` detector for `params.exclude` (a comma-separated list of child base names, case-insensitive), in `registry.go`.
- Add `exclude: Google,JetBrains` to `user.logs`.

- Keep the catalog-wide overlap test from P3-R1 passing.

**D11 (R1-11): projects in protected folders.** `projectDirs` skips nodes for which `safety.Policy.IsProtected` is true (policy from `env.Home`).

**D12 (Downloads).**
- `user.downloads_large_old` (quarantine, CAUTION) emits only files whose extension, matched case-insensitively, is one of: `.dmg .pkg .mpkg .xip .zip .iso .tar .tgz .gz .bz2 .xz .7z .rar .ipa .apk .aab`.
- Add a new advise-only recipe `user.downloads_large_other` (category `downloads`, toolchain `system`) for other large old files directly in `~/Downloads`, with the same thresholds.
- In both, `restore.note` says other files "may be the only copy". The installer recipe says "re-download from the original source".

**D13 (app caches).** `user.app_caches` gets `stale_days: 14`.

**D14 (venv).** `python.venv_stale` risk becomes **RISKY**, per SAFETY_MODEL §2: a venv may hold local edits, and the restore depends on pins.

**D15 (ollama relative dates).** Parse ollama `MODIFIED` relative forms into an approximate `LastUsed`:
- `N seconds/minutes/hours/days/weeks/months/years ago`
- `About a minute ago`
- `About an hour ago`
- `Less than a second ago`

Take a month as 30 days and a year as 365. Anything else stays unknown.
