# Task P2-W1: full-crawl scanner (bounded memory, background priority)

**Role:** implementer · **Branch:** `task/P2-W1` · **Phase:** 2 · **Runs in parallel with P2-W2** (store). Never touch their files.

## Goal
Implement `internal/scanner`: a parallel, read-only walker of the Data volume that measures **allocated** bytes, keeps only significant nodes, and stays within a strict memory budget on an 8 GB Mac.

## Requirements
1. **Correct sizes.**
   - Count allocated bytes (`Stat_t.Blocks * 512`), not logical size, so sparse files count only what's allocated.
   - Directories count their own blocks too.
   - Symlinks are `lstat`ed and never followed. Count the link's own blocks, usually 0.
2. **One device.** Never descend into a directory whose `st_dev` differs from the root's.
3. **Hard links.** Count a regular file with `nlink > 1` once per `(dev, ino)`, up to `HardlinkLimit`. After that, count every link and set `HardlinkLimitHit`.
4. **Bounded memory, streaming aggregation.**
   - Never hold the whole tree. A directory's totals roll up into its parent when all its children are done.
   - Only nodes passing the keep rules survive: `Bytes >= KeepThreshold`, or `Keep(path)` is true, or it's the root.
   - **No descendants of `Opaque` paths are kept**, though their bytes still count.
   - `Skip` paths aren't descended and aren't counted.
   - Memory must not grow with the number of files below the threshold.
5. **Parallelism.**
   - `Workers` concurrent directory readers (default 4).
   - A bounded queue: no unbounded goroutine fan-out, and no one goroutine per directory left waiting.
   - Work must keep going even on very deep trees.
6. **Errors.**
   - `EACCES`/`EPERM` on a directory produces an `Unmeasured{mapped path, "permission denied (grant Full Disk Access to your terminal)"}`.
   - An entry that vanished mid-scan (`ENOENT`) is ignored silently.
   - Any other error produces an `Unmeasured` with `err.Error()`.
   - An unusable root (missing, not a directory) makes `Scan` return an error.
7. **Cancellation.** Watch `ctx`. On cancel, stop promptly (under 1 s on fixtures) and return the partial result with `Incomplete=true` and a nil error. Leak no goroutines; check in tests (e.g. `runtime.NumGoroutine` settles, or use `goleak`-style polling without adding a dependency).
8. **Progress.** Call `Progress` at most every `ProgressEvery`, from one goroutine at a time (never concurrently).
9. **Path mapping.**
   - Apply `MapPrefix` to every reported path (Nodes, Unmeasured, Progress) and to the `path` passed to `Keep`.
   - `Depth` counts components below the root.
   - Skip and Opaque compare against **unmapped** absolute paths, case-insensitively.
10. **Output.**
    - Nodes are sorted by Bytes descending, ties broken by Path ascending.
    - `MtimeMax` is the newest mtime (seconds) of anything below.
    - `Files` counts regular files.
    - A single file ≥ threshold is kept as a `NodeFile`.
11. **Priority.** `SetBackgroundPriority()` calls `syscall.Setpriority(4 /*PRIO_DARWIN_PROCESS*/, 0, 0x1000 /*PRIO_DARWIN_BG*/)`, or the `unix` equivalent, with no exec and no cgo.
    - `Scan` itself must **not** change priority. The CLI decides.
    - Test that it returns nil. This lowers the test process, which is fine.

## Tests (use `fstree` fixtures under `t.TempDir()`)
- **Sizes:** sparse file ≈ 0 allocated, hard link counted once (and counted twice past a limit of 1), symlink not followed (a link to a huge dir adds ~0).
- **Keep rules:** threshold, `Keep` callback, root always present, Opaque descendants never kept but counted, Skip neither descended nor counted, and case-insensitive Skip/Opaque matching.
- **Mapping:** a fake root with a `MapPrefix` maps correctly in Nodes, Unmeasured, Progress and `Keep` input.
- **Errors:** a locked directory (`WithMode(0)`) becomes Unmeasured, and the rest of the tree is still counted. A missing or file root returns an error.
- **Cancellation:** cancel during a large synthetic tree returns `Incomplete` quickly with no goroutine leak.
- **Concurrency:** `go test -race`, with Workers = 1, 4 and 16 giving identical results.
- **Cross-device:** if you can't create a second device in tests, unit-test the dev check via an injectable stat function and explain it in the report.
- **Benchmark** `BenchmarkScanSynthetic`: a generated tree of ~200k small files across ~20k dirs. Report ns/op, allocs and **peak heap** (sample `runtime.ReadMemStats` HeapInuse in a goroutine). Target: peak heap ≤ 48 MB with the default threshold.
- Optional real-volume smoke test, gated by env `MACDOC_REAL_SCAN=1` (skipped by default). It scans `$HOME/Library/Caches` and prints totals. Don't run a full-volume scan; the tech lead will.
- Coverage ≥ 90%.
