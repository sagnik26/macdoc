## Attack ideas (not exhaustive, so be creative)
- **Path tricks:** `..` after symlinks, `//`, trailing `/.`, `/./`, very long paths, paths with `\n` or `\r`, NUL, unusual Unicode (NFD vs NFC, compatibility forms like full-width `／`, zero-width joiners, homoglyphs in protected names, Turkish dotless `ı` vs case folding).
- **Case:** `~/DOCUMENTS/x`, `/SYSTEM/Library`, `~/.SSH/key`, `.GIT`.
- **Symlinks:** a parent symlink into `~/Documents` or `/System`, chains of symlinks, a symlink to `/`, a symlink loop, a relative-target symlink climbing out of home, a symlink created *after* Canonicalize (document it as a TOCTOU note for Phase 6; the executor re-validates).
- **Home exception abuse:** can a path outside home under `/private` sneak through when home is a temp dir? Can a crafted home make the exception cover something it shouldn't?
- **Allow patterns:** patterns that are too broad (`~/**`, `/**`, `~/*`), pattern injection (`~/../`, `~user/`), `**` at odd positions, and case and Unicode mismatches between pattern and path.
- **Depth rule:** `~/x`, `~/./x/..`, home with a trailing slash.
- **Pattern rules:** `.git` as a substring vs a component (`my.git.repo` should NOT be protected, `.git` should be), `.env.local`, `.envrc` (decide whether it should be protected and argue it in the report), `x.DB`, `x.sqlite-wal`.
- **Sandbox:** env var with a trailing slash, a symlinked sandbox dir, a sandbox equal to an ancestor of home, an empty string vs unset, a path equal to the root, the fail-closed check.
- **Fuzz:** extend the fuzz corpus with seeds from your findings.

## Output

2. Commit on `task/P0-R1`.
3. Write `.task/REPORT.md` with:
   - A findings table (ID, severity critical/high/medium/low, description, failing test name, suggested fix)
   - Attacks tried that held up
   - Spec ambiguities found in the briefs (e.g. `.envrc`)
4. Write `.task/last-test.txt` (e.g. `3 BUG tests failing · 41 passing`).

Then stop and wait.
