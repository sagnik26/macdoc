# P0-W1 report (archived by tech lead)

**Result:** merged in `0ec2cdf` (commits `3cb9605`, `1ca6460`) · 2 rounds · ~10 min of worker time

## Implemented
`internal/safety`:
- `Canonicalize`:
  - rejects empty input, NUL bytes, relative paths and `..` components
  - resolves symlinks in the parent chain only (the final component is never followed)
  - NFC-normalizes the result
- `Within` / `IsProtected` / `CheckTarget`:
  - case-insensitive matching via Unicode full case folding
  - system roots, home-relative roots, `.git` / `.env*` / `*.db` / `*.sqlite*` pattern rules, and `com.apple.*` containers
  - strict ancestors and siblings of `$HOME` are protected
  - depth ≥ 2 below `$HOME`
  - allow patterns with `*` / `**`, matched in linear time
- Symlinked protected folders are protected both as the link and at its target.
- Home containment exception, so `t.TempDir()` homes work.

## Decisions made in review
| Q | Decision |
|---|---|
| `..` cleaned before resolving symlinks can disagree with the kernel | **Reject** any input with a `..` component (round 1) |
| Other users' homes and `/Users/Shared` | **Protected:** siblings of `$HOME` are never targets (round 1) |
| Absolute allow patterns with non-canonical prefixes (`/var/...`) never match | Deferred to the **Phase 3 recipe lint** (also reject `..` in patterns there) |
| `.db` / `.sqlite` always protected | Intended: files can't be targets, but directories containing them can |
| All of `/opt` protected | Intended |
