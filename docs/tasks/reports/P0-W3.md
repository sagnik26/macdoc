## Per-decision changes

| ID | Change |
|---|---|
| D1 | `isProtected` now rejects a strict ancestor of any non-system root (home-relative, extras, both lexical and resolved forms, which `addRoot` already stores). | D1 (Containers) | `~/Library/Containers` **itself** and its ancestors are reported as `contains protected path <Containers>/com.apple.*`. The P0-R1 test expects the Containers dir itself to be protected, and it is a strict ancestor of the `com.apple.*` entries. See Q1. |
| D2 | `Canonicalize` rejects any input other than `/` that ends in `/` or `/.` with `*Violation{RuleInvalid, "trailing slash or /."}`. The `..` check still runs first. Inner `.` and `//` are still cleaned. Policy roots (home, extras) and the `MACDOC_SANDBOX`/`HOME` values are cleaned lexically before canonicalizing, so trailing slashes stay accepted there. Values with `..` are left uncleaned so they are still rejected. Doc comment updated. |
| D3 | Final components ending in `<suffix>{,-wal,-shm,-journal}` for `.sqlite`, `.sqlite3` and `.db` are protected. |
| D4 | Any final component whose folded form starts with `.env` is protected. |
| D5 | `Policy.containers` holds the lexical and `resolveFull` forms of `~/Library/Containers`, both used for the `com.apple.*` rule and D1. The P0-R1 test creates the Containers symlink **after** `NewPolicy`, so `CheckTarget` also re-resolves Containers on each call (`currentContainers`). If that fails (e.g. a symlink loop), it falls back to the policy-time forms. `IsProtected` stays lexical and uses the policy-time forms. `NewPolicy` returns an error if Containers can't be resolved. |
| D6 | `CheckTarget` order is now canonicalize → protected → outside-home → depth → allow. Any path not within home returns `RuleOutsideHome`. Added `/.vol`, `/.file`, `/Network`, `/net` and `/home` to system roots. Updated the `CheckTarget` and `RuleOutsideHome` comments. `depthOK` was simplified because it now runs only within home. |
| D7 | `NewPolicy` rejects a resolved home within any system root unless it is **strictly** below `/private/var/folders` or `/Volumes` (`checkHomeLocation`). Doc comment updated. The containment exception is unchanged and is tested with a lexical `/Volumes/macdoc-nonexistent-vol/home`. |
| D8 | `sandbox.Check` runs `safety.Canonicalize(path)`. It refuses on error or if the result isn't `samePath` with the input. Doc comment updated. |
| D9 | Added `safety.SystemRoots()`, which returns a copy. `sandbox.Root` rejects a root that equals or contains a system root (`covers system path`). It also rejects a root within a system root unless the root is **strictly** below `/private/var/folders` or `/private/tmp` (`inside system path`). Doc comment updated. |
| D10 | `Root` uses `os.LookupEnv`. Unset means inactive. Set but empty or whitespace returns `"", true, error`, so `Check` fails closed. Doc comment updated. |
| A5 | The `IsProtected` doc comment now says loudly that input must be canonical and that non-canonical input can miss symlinked parents. |
