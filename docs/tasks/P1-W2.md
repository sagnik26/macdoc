## Semantics
- **ParseDiskutilInfo:**
  - Container ref comes from `APFSContainerReference`.
  - Total comes from `APFSContainerSize` (fall back to `TotalSize`).
  - Free comes from `APFSContainerFree` (fall back to `FreeSpace`).
  - Return an error if no container reference is found (e.g. a non-APFS volume) or the plist is invalid.
- **ParseAPFSList:**
  - Find the container whose `ContainerReference` equals `containerRef`.
  - For each volume, record `Name`, `Roles` (the array as is, e.g. `System`, `Data`, `VM`, `Preboot`, `Recovery`, `Update`) and `CapacityInUse` → `UsedBytes`.
  - Fill `MountPoint` only if it's present in the plist. Don't call mount.
  - Sort by `UsedBytes` descending.
  - Unknown container → error.
- **ParseLocalSnapshots:**
  - Skip the `Snapshots for disk /:` header and blank lines. Each remaining trimmed line is a name.
  - Output that says the disk has no snapshots, or the header only, means `Count` = 0 with no error.
- **CollectDisk:**
  - Run `diskutil info -plist /`, then `diskutil apfs list -plist` (timeout 15 s each).
  - Fill `Disk`, then fill `PurgeableBytes` (below).
  - If the apfs list fails, still return the container sizes, with a wrapped error that the caller can turn into a warning. Document how partial results are returned.
- **CollectSnapshots:** run `tmutil listlocalsnapshots /`.
- **Purgeable (optional cgo):**
  - Add `internal/platform/darwin`. It contains `purgeable_cgo.go` (build tags `darwin && cgo`), which uses Foundation `NSURL` resource values for `/`: `NSURLVolumeAvailableCapacityForImportantUsageKey` minus `NSURLVolumeAvailableCapacityKey`, clamped at ≥ 0. It also contains `purgeable_stub.go` (`!darwin || !cgo`), which returns "unknown".
  - Expose `func PurgeableBytes() (int64, bool)`.
  - `CollectDisk` sets `PurgeableBytes` to `model.Bytes{Value: n, Source: model.SourceMeasured}` when ok, otherwise `{Source: model.SourceUnknown, Reason: "purgeable space needs the cgo build"}`.
  - **No exec in the shim.** Keep the cgo minimal and free all Objective-C objects (use `@autoreleasepool`).
  - If cgo turns out to be impractical, ship only the stub and explain why in your report.
- **Commands:** fixed argv only via `platform.Command`, with no shell. **Never** call any mutating diskutil or tmutil subcommand. Only `info`, `apfs list` and `listlocalsnapshots`.
- **Errors:** wrap with context, and include trimmed stderr on a non-zero exit.
